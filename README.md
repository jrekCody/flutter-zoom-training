# Flutter Zoom

A flutter zoom clone application.

### Getting Started
- run command to generate the required dependencies.
```flutter packages pub run build_runner build```
- run the app. ```flutter run```


### Implementing the following features

- Firebase Auth (Google Provider) `google_sign_in`
- [Jitsi Meet](https://pub.dev/packages/jitsi_meet_flutter_sdk)
    - Create Meeting
    - Join Meeting
    - Mute/UnMute Audio
    - Video On/Off
- Display meeting history realtime
